# 07. 软件测试计划

> D1 · 2026-09-23 · 所有产品用例状态均为 Not Run。本目录暂无源码、Qt Test 可执行文件或发布包；文档检查不能替代产品测试。

## 1. 测试层级与环境

单元测试用 Qt Test/CTest；集成测试使用独立模拟器和临时数据库；系统测试验证 UI、负载和部署。测试不写用户实际数据库，不依赖公网设备。状态机/重连/告警注入单调时钟与随机源，不用长时间 sleep 判断逻辑。

记录 OS、CPU/RAM、磁盘空闲、Qt/编译器/CMake/SQLite 版本、构建模式、提交或源码 SHA256、配置和模拟种子。Windows/Ubuntu 各自记录结果；一端通过不能代表跨平台通过。

## 3. 负载与统计口径

基准：10 TCP 设备，各 10Hz 四指标；UI 100ms 合并；SQLite 全量样本异步落盘，默认配置、Release。UDP/串口有独立集成测试，不把 10 个物理串口作为负载前提。

- 30min 为 180000 帧、720000 样本的名义量；8h 为 2880000 帧、11520000 样本。以模拟器实际计数及统一开始/结束屏障核对，不因调度漂移强行要求名义量。
- 先结束采集再排空 DB；核对发送、合法接收、持久化、明确丢弃和未提交数。故障注入场景与无故障稳定性分开。
- GUI 每 100ms 记录一次单调时钟探针，额外延迟=max(0,实际间隔-100ms)。30min P95≤100ms、最大≤500ms；同负载同时记录 CPU 与队列峰值。
- 8h 每分钟记录 RSS/Private Bytes、线程数、队列长度、DB/WAL/日志大小。预热 30min 后，末 30min 内存中位数减去首个 30min 中位数≤50MiB，且小时中位数线性拟合斜率≤5MiB/h。
- 内存阈值是工程验收线，不是数学上的无泄漏证明；另做一次 ASan 或 Valgrind 针对关闭/重连路径的检查。不能跨 OS 比较不同口径的内存指标。
- 磁盘不足/环境中断标 Blocked，不缩短 8h 后声称稳定性通过。

## 4. 阶段门禁与结果

阶段冒烟：3 个设备运行 30min，验证当前阶段路径；不能替代最终 10 设备/8h 验收。最终要求所有必需需求有实现证据与对应通过结果；AUTO 至少 20 条不替代上述关键边界；无未关闭 P0/P1。

结果状态：Not Run / Pass / Fail / Blocked / N/A。N/A 仅用于可选功能并说明理由，不能用于跳过必需功能。无串口测试环境则必需串口用例 Blocked；有虚拟串口可完成主线验收，但只能证明虚拟链路。未选择实物扩展时实物拔插记 N/A，不能据此宣称硬件联调通过。

缺陷等级：P0 崩溃/数据损坏/完全不可用；P1 核心功能失效；P2 局部异常有绕过；P3 体验问题。每条缺陷保存版本、环境、前置条件、步骤、实际/预期、日志、根因、修复与回归。

测试报告至少记录：运行 ID、时间、版本/hash、环境、配置/hash、种子、用例 ID、结果、实际值、日志/截图路径、缺陷 ID。未运行绝不能生成绿色通过报告。
