# 02. 软件需求规格说明书 SRS

> D1 · 2026-09-23 · 待实现。范围依据：[PRD](01_PRD.md)。以下为设计要求，不代表已有实现或测试结果。

## 1. 系统范围与术语

系统由桌面客户端、独立设备模拟器和 SQLite 数据库组成。TCP/串口支持双向协议，UDP 接收单播遥测。所有数据来自模拟器或测试环境；模拟器联调不等于实物联调。

- 帧：一条完整协议消息；样本：帧中一个指标值；10Hz 指每设备每秒 10 个遥测帧。
- 在线：收到来源正确、类型支持、CRC 和载荷有效的消息，不只看 socket 是否建立。
- 时间：落盘使用 UTC Unix 毫秒；超时使用单调时钟。设备采样时间与客户端接收时间分别保存。
- 阶段 S1–S8 见 PRD。应/必须表示必需条件；所有需求当前为 Planned。

## 2. 外部接口

| 接口 | 约束 |
|---|---|
| TCP | 主动连接；每会话独立流缓存；见 [协议](05_PROTOCOL_SPEC.md) |
| UDP | 本地绑定；来源 IP/端口映射设备；一报一帧，不跨报重组 |
| 串口 | 默认 115200、8 数据位、无校验、1 停止位、无流控 |
| 配置 | devices.json + app.ini；完整校验后应用；见 [配置](15_CONFIGURATION.md) |
| 数据库 | SQLite schema 初版为 1；见 [数据库](06_DATABASE_DESIGN.md) |
| 日志/CSV | UTF-8；运行数据不依赖启动时的当前工作目录 |

| ID | 对应 PRD | 可测要求 |
